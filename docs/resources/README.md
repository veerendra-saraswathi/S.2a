## Publication convention

When a file is added, list its exact filename, document date, revision, covered product version, intended audience and status. Link both the editable source and its PDF export when available. A suggested filename pattern is `Samanvaya_2_<Topic>_<Revision>_<YYYY-MM-DD>.<extension>`.

Future files can live under `docs/resources/word/`, `docs/resources/pdf/` and `docs/resources/presentations/`. Those directories and download links will be created when actual files are added, so the landing page does not advertise unavailable downloads.

The repository's proprietary license applies to first-party materials. Source documents should be reviewed for outdated claims and customer-specific information before publication.
